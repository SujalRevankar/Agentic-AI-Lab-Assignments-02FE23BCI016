# Course Project Source Code

This is a clean copy of the Meeting Organizer Agent source tree from the supplied working project. It includes the backend, frontend, database migrations, tests, evaluation scripts, Docker configuration, and project documentation.

The snapshot excludes local credentials, databases and backups, virtual environments, build caches, editor metadata, and the older research report with superseded evaluation claims. Start from `.env.example` and configure only the integrations you need. Do not commit a populated `.env` file.

For the local app setup and evaluation commands, see `README.md` and `evaluation/README.md`. A local credential-free workflow can use the mock calendar and seeded data.
